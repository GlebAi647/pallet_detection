# Бенчмарк модели pallet_detection (model_pallet_29.04.25)



Выбранный фреймворк : Ultralytics YOLOv8.

## Обоснование:

_YOLOv8_ — это современный фреймворк для задач детекции объектов, который предлагает высокую скорость и точность.
Удобный API для обучения, вывода и экспорта моделей.
Поддержка небольших версий моделей (например, yolov8n), что идеально подходит для устройств с ограниченными ресурсами.
Широкая документация и активное сообщество.

## 1. Выбор архитектуры модели
Выбранная архитектура : YOLOv8 Nano (yolov8n), с последующей конвертацией в ONNX формат со встроенным NMS

- **Производительность**: Модель обеспечивает высокую скорость вывода (до 100+ FPS на GPU и до 10-15 FPS на CPU).
- **Точность**: Несмотря на небольшой размер (3,2 млн. параметров), модель сохраняет достаточную точность для задач детекции объектов.
- **Размер модели**: Модель занимает всего несколько мегабайт (model_pallet_29.04.25.pt = 6,1 мб, model_pallet_29.04.25.onnx = 12 мб),
- **Архитектура**: Поддержка сверточных блоков C2f (лучшее качество детекции при малых размерах)
- **Итог**: все выше перечисленное делает её идеальной для развертывания на устройствах с ограниченными ресурсами.

Сравнение с аналогичными решениями:
- **YOLOv8 Nano**, размер ~4 MB, fps (cpu) = 8-12, точность ~30%, платформа Raspberry Pi
- **YOLOv5s**, размер ~14 MB, fps (cpu) = 5-8, точность ~37%, платформа Raspberry Pi
- **MobileNetV3-SSD**, размер ~20 MB, fps (cpu) = 15-20, точность ~20%, любой CPU-only
- **EfficientDet-Lite**, размер ~5 MB, fps (cpu) = 6-10, точность ~35%, мобильные устройства
- **ИТОГ**: YOLOv8 Nano Лучший баланс скорости/точности с оптимизацией (OpenVINO)

### 1.1. Производительность системы

Предполагаемое тестовое устройство: Например, Raspberry Pi 4 (4GB RAM, CPU Cortex-A72).
- **Производительность**: FPS: ~10-15 (в зависимости от разрешения видео)
- **Задержка**: ~100-150 мс.

### 1.2. Применение технологий обработки видеопотока
- **Инструменты**: OpenCV, GStreamer.

- OpenCV : Простота использования и широкая поддержка.
- GStreamer : Более эффективная работа с видеопотоками, особенно на Linux-based устройствах (Raspberry Pi).

# 1.3. Оптимизация

- Использование YOLOv8n + OpenVINO (лучшее сочетание скорости и точности), Для RPi 5 с OpenVINO можно достичь 15+ FPS на CPU
- **OpenVINO**: специально разработан Intel для ускорения нейросетей на CPU, использует AVX/SSE инструкции 
(активно задействует все ядра RPi), автоматически применяет **квантование** INT8 (ускорение в 1.5–2× без потери точности),
оптимизирует граф модели, удаляя лишние операции (отдельно сохранена модель с int8 по пути:
**model_pallet_detection/exploration/pallet_detection/experiment_1/weights/model_pallet_29.04.25_int8_openvino_model**: где:
1) metadata.yaml
2) model_pallet_29.04.25.bin
3) model_pallet_29.04.25.xml
