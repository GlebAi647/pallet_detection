# Аналитическая записка по обучению и предсказаниям модели model_pallet_29.04.25

### Конфигурация обучения:

- Модель: YOLOv8n (нано-версия)
- Эпохи: 200
- Размер изображения: 1280x1280
- Batch size: 8
- Оптимизатор: Adam
- Learning rate: 0.01 с warmup в течение 3 эпох
- Аугментация: включена (RandAugment)

### Анализ процесса обучения:
1) Loss функции: 
- Box Loss (train): Снизился с 0.88 до 0.25, что свидетельствует о хорошей сходимости модели в определении bounding box'ов.
- Class Loss (train): Упал с 2.92 до 0.17, что показывает улучшение в классификации объектов.
- DFL Loss (train): Уменьшился с 1.23 до 0.79, демонстрируя улучшение в предсказании распределения объектов.
2) Validation метрики:
- mAP50: Вырос с 0.5867 до 0.86396, достигнув пика на 200 эпохе
- mAP50-95: Улучшился с 0.5867 до 0.86396, что показывает хорошую обобщающую способность модели.
- Precision: Увеличился с 0.74689 до 0.97662.
- Recall: Вырос с 0.76003 до 0.96353.

### Графики обучения:
1) Динамика метрик точности:
- Все метрики (Precision, Recall, mAP) демонстрируют устойчивый рост на протяжении всего обучения.
- После 100 эпохи рост метрик замедлился, что указывает на приближение к пределу возможностей модели.

2) Loss функции:
- Все три компонента loss (box, cls, dfl) показывают плавное снижение без резких колебаний.
- Validation loss следует за train loss, что говорит об отсутствии переобучения.
