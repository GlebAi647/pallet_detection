# 📦 Pallet Model detection 

## Проект для детекции событий (человек, паллет, брезент) с использованием модели ONNX (yolov8n).

--------------------------------

##  Описание

Проект представляет собой модульную систему обработки видео с целью:

1) Детектирования объектов классов: человек (human), паллета (pallet), брезент (present).
Сохранения результатов в виде:
Отмечено видео с боксами и текстом.
Таблицы с координатами и уверенностью предсказания (Excel).
Кадры событий (человек, покрытие паллет, и т.д.).
Модель ONNX запускается на CPU, проект использует OpenCV, Pandas, Matplotlib и другие библиотеки.
А также выходной аналитики результатов детекции и работы программы.
--------------------------------

## 🛠️ Установка зависимостей

#### pip install -r requirements.txt

--------------------------------


## ⚙️ Как запустить



1) Убедитесь, что все пути указаны в **model_pallet_detection/config/configuration.py**(


   _model_path_ - путь к модели onnx

   _video_path_ - тестовое видео на котором будем тестировать

   _output_excel_path_ - excel файл с результатами детекции

   _output_video_path_ - видео с результатами инференса с отрисованными box и видеоаналитикой

   _events_dir_ - папка куда сохранить кадры с event


2) Запустите основной скрипт: _python run_detection_pipeline.py

--------------------------------

## 📊 Что происходит под капотом



✅ Процессинг видео по кадрам.

✅ Детекция объектов с помощью ONNX модели.

✅ Сохранение результатов в Excel файл.

✅ Визуализация bounding box'ов и текста на видео.

✅ Сохранение событий (человек, покрытие паллет).

✅✅ Поддержка выходной аналитики предсказаний: графики, статистика по уверенности, временные метки.

## **📈 Аналитика инференса**

--------------------------------

Есть возможность отдельно запустить анализ результатов инференса запустив скрипт по пути **model_pallet_detection/analitics/analitics_inference.py**:

1) Графики распределения уверенности (confidence) по классам.
2) Минимальная и максимальная уверенность на каждом кадре.
3) Общая статистика сохраняется в текстовый файл.
